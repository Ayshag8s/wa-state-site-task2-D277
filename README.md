## Website for school assignment- Washington state & three cities webpage
### Required of the assignment:
- Should have the base components of a website: header, working navigation bar, aside section, main content, and footer.
- Info on Washington state and 3 cities within, in an ORDERED list. Population, when location founded, general location, scale of city development (rural, suburban, urban), and average income.
- Photos of each city's page, and a scroller for all site photos on the home page.
- A form to fill, with the ability to check if emails match. Did not require for it to actually send the message anywhere though, I plan to come back and add that for fun.
- It needed to look good, with style elements loading in accordingly.
- Working links.
